# Italy itinerary · Sep–Oct 2026

Family trip planner — Milan, Lake Como, Venice, Verona. One HTML file, no build step.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The itinerary. Open this. |
| `italy-itinerary-images/` | Photos used in the side panels. Keep it beside `index.html`. |
| `.nojekyll` | Needed for GitHub Pages so Jekyll does not break image paths. |

## Running locally

Open `index.html` in a browser. Password: `italy2026`.

## GitHub Pages

Published at [github.com/trivituso81/italy2026](https://github.com/trivituso81/italy2026).

When you upload changes, drag in **`index.html`**, **`italy-itinerary-images/`**, and **`.nojekyll`** — the same three things that live in this folder.
